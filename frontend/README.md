# EchoMind Frontend

This directory contains the React frontend for the EchoMind project, built with Vite.

Please refer to the [Root README](../README.md) for full instructions on setting up and running the entire project (both backend and frontend).

## Quick Start

```bash
npm install
npm run dev
```

The app will start on `http://localhost:5173`. Ensure the backend API is running on `http://localhost:8000`.
